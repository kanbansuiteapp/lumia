# Prompt: análisis visual en Markdown (Paso 2a)

Versión corta del análisis. Se ejecuta en un LLM multimodal con las fotos base y su salida se guarda como archivo de conocimiento.

```text
Analiza minuciosamente de forma visual y especializada todas las fotos de esta persona. Genera un desglose detallado en formato Markdown con sus parámetros físicos exactos para garantizar la consistencia visual:
- Rostro: forma de la cara, estructura ósea, ojos, mirada, cejas y labios.
- Piel: textura, tono, pecas e imperfecciones naturales.
- Cabello: color, estilo, textura, densidad y volumen.
- Expresión y lenguaje corporal: actitud habitual, tipo de sonrisa y postura.
Proporciona la respuesta en texto Markdown limpio sin explicaciones adicionales para guardarlo como archivo de conocimiento.
```
